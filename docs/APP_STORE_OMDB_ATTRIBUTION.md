# OMDb Attribution for App Store

Use these when resubmitting after the 2.3.3 / 4.1.0 / 5.2.1(e) rejection.

---

## 1. In-App Attribution (DONE)

- **About** page: "About This App / Data Sources" card with OMDb attribution.
- **Settings** page: "Data Sources" card with OMDb attribution.
- **Privacy** page: Section 5 already mentions OMDb and links to omdbapi.com.

---

## 2. App Store Connect → App Description

Add this block at the **bottom** of your app description:

```
Data Attribution

This app uses the OMDb API to provide movie information and posters. OMDb API is a licensed movie database service. https://www.omdbapi.com

This app is not affiliated with or endorsed by OMDb.
```

---

## 3. Resolution Center Reply to Apple

Go to: **App Store Connect → Your App → App Review → Resolution Center**

Send this message:

```
Hello,

Thank you for your feedback. We have updated the app to address the metadata and intellectual property points (2.3.3, 4.1.0, 5.2.1(e)):

1. In-app attribution: We now show clear OMDb API attribution in two places reviewers can see without logging in:
   - Settings → "Data Sources" section (movie data and posters from OMDb API, with link to https://www.omdbapi.com and the required disclaimer).
   - About → "About This App / Data Sources" section (same attribution).

2. Our Privacy Policy (accessible from the landing page and in-app) already states in section 5 that we use the OMDb API for posters and metadata and links to https://www.omdbapi.com.

3. We have added a "Data Attribution" paragraph to the App Store description, stating that we use the OMDb API and are not endorsed by OMDb.

Movie posters and metadata are used in accordance with the OMDb API terms of use. We are happy to provide any further details or screenshots if needed.

Best regards,
[Your name]
```

---

Replace `[Your name]` with your name before sending.
