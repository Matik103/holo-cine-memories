## About the app

**CineMind Pro** is a personal movie discovery and memory companion. It helps users:

- **Recall movies from vague memories** — Users type a short description (e.g. “robot loves human”, “spinning dreams”) and the app identifies the movie using AI.
- **Discover similar movies** — After identifying a film, users can explore similar titles, themes, and where to watch.
- **Build a personal profile (CineDNA)** — Signed-in users get recommendations that improve with their search history.
- **Watch trailers and find streaming options** — The app surfaces trailers and streaming availability for identified movies.

The app can be used **without an account** (Continue as Guest on the Sign In screen). Sign-in is optional and used to save search history and personalize recommendations.

**Third-party data:** Movie metadata (titles, years, plots, posters) is supplied by the **OMDb API** (https://www.omdbapi.com). We use it under OMDb’s terms of service and provide clear attribution in the app and in the App Store description.

---

## What to check during review

1. **In-app attribution**
   - **Settings** (gear icon) → scroll to **“Data sources”** — OMDb is credited with a link to https://www.omdbapi.com.
   - **About** (from main menu or profile) → **“About This App / Data Sources”** card — same OMDb attribution and disclaimer.

2. **App Store listing**
   - The app description includes a line crediting the OMDb API and/or data sources where required.

3. **Guest access**
   - On the **Sign In** screen, “Continue as Guest” allows full use of the core feature (movie recall) without creating an account.

4. **No copy of other apps**
   - The concept, UI, and flows (describe a memory → get a movie → similar titles, meaning, streaming) are original to CineMind.
